# v4 熊市参数实验设计

## 目标

在不修改 `scripts/bbi/backtrader/v4` 主策略的前提下，在 `scripts/bbi/backtrader/tmp` 中建立 2018 年熊市专项实验，测试能否通过市场牛熊门禁和回撤阈值调整，让策略在 2018 年减少大亏，优先争取正收益。

## 背景结论

当前 v4 的 2018 年表现：

- 年收益约 `-51.17%`
- 最大回撤约 `-55.46%`
- 卖出交易合计亏损约 `-27.23 万`

根因不是单一的 `pullback_120 <= -9%`，而是熊市里仍然持续做多。外部资料也支持先做市场状态过滤：常见做法是用指数站上长期均线或中期 BBI 判断牛熊；回撤买点通常还要结合均线、支撑和重新走强确认。

## 实验设计

使用现成数据：

- `scripts/bbi/backtrader/v4/output/panel.parquet`
- `scripts/bbi/backtrader/v4/output/market_index.parquet`
- `scripts/bbi/backtrader/v4/output/nav_series.csv`
- `scripts/bbi/backtrader/v1/output/stats_summary.csv`

新增实验脚本：

- `scripts/bbi/backtrader/tmp/v4_bear_2018_experiment.py`

实验范围：

- 只调 2018 年，不用未来数据。
- 每个交易日开盘只使用前一完整交易日信号。
- 保留 v4 的核心强势排名和个股过滤。
- 参数化首笔买入回撤阈值：`-5%`, `-6%`, `-7%`, `-8%`, `-9%`, `-12%`, `-15%`。
- 参数化市场门禁：
  - `none`：不加长期门禁。
  - `ma120`：上证收盘价高于 120 日均线才允许新开仓。
  - `ma200`：上证收盘价高于 200 日均线才允许新开仓。
  - `bbi_5_20_60_120`：上证收盘价高于中期 BBI 才允许新开仓。
  - `ma120_or_bbi`：上证高于 120 日均线或中期 BBI 才允许新开仓。

## 评审结论

策略专家：

- 如果目标是 2018 熊市赚钱，第一优先级不是把 `-9%` 调浅，而是市场门禁。
- 回撤阈值从 `-9%` 调到 `-7%` 可能减少接深跌股票，但不解决系统性下跌。

数据 QA：

- 实验脚本必须只读 v4 输出文件。
- 信号日必须是交易日前一日，不允许使用当日收盘判断当日开盘。

验收工程师：

- 输出必须至少包括：参数、2018 收益率、最大回撤、Calmar、交易次数、买入次数、卖出盈亏。
- 必须给出和 v4、v1 的比较。
