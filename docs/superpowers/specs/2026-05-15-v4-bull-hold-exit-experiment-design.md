# v4 强趋势持有卖出实验设计

## 目标

在不修改 `scripts/bbi/backtrader/v4` 正式策略的前提下，只在 `scripts/bbi/backtrader/tmp` 做强趋势持有实验，重点回答一个问题：当前 v4 对放量大阴线卖出是否过早，是否存在一套更稳的强趋势持有规则，能在不引入未来函数的前提下改善 2018 熊市表现，并尽量拿住类似中际旭创、新易盛这类强趋势股票。

## 已知前提

- 当前正式 `v4` 已有完整 `panel.parquet`、`market_index.parquet` 和回测结果。
- 之前做过“洗盘确认/延迟卖出”实验，结果明显变差，因此这条思路不继续推进。
- 用户当前优先关心 `2018` 年熊市效果，因此第一轮实验先只跑 `2018-01-01 ~ 2018-12-31`。
- 所有交易决策继续遵守现有口径：`T` 日开盘成交，只能使用 `T-1` 日收盘及更早数据。

## 实验范围

本轮只改“持仓后的卖出/继续持有逻辑”，不改以下内容：

- 股票池
- 打分与候选排序
- 首笔买入回撤条件
- 加仓条件
- 手续费和成交约束

新增 5 个实验模式：

1. `current`
   - 当前 v4 逻辑，作为基线。
2. `trend_line`
   - 对强趋势且已有利润垫的持仓，放宽单日放量大阴线卖出；
   - 改为跌破持有线才卖。
3. `profit_cushion`
   - 按利润垫分层处理；
   - 利润越厚，容忍度越大。
4. `strict_observe`
   - 强趋势且盈利较厚时，放量大阴线后进入短观察，不立即卖；
   - 但只允许严格失败条件，不做宽松“洗盘确认”。
5. `weekly_hold`
   - 强趋势且已有利润垫时，改用周线 10 周/20 周持有规则，而不是日线大阴线立即卖。

## 方案定义

### 1. current

完全复用当前 `v4` 的卖出逻辑：

- 止损
- 跌停风控
- 放量大阴线次日开盘卖出

### 2. trend_line

适用范围：

- 个股满足 `strong_trend=True`
- 且持仓浮盈 `>= 10%`

处理规则：

- 命中放量大阴线时，不立即触发卖出；
- 只有当 `T-1` 日收盘满足以下任一条件时，才在 `T` 日开盘卖出：
  - `close_qfq < bbi_qfq`
  - `close_qfq < ma20_qfq`
  - 放量大阴线且 `close_qfq < ma50_qfq`

不适用时：

- 仍按 `current` 规则执行。

### 3. profit_cushion

分层规则：

- 浮盈 `< 10%`：按 `current`
- 浮盈 `>= 10%` 且 `< 20%`：
  - 放量大阴线不直接卖；
  - 只有 `close_qfq < bbi_qfq` 或 `close_qfq < ma20_qfq` 才卖
- 浮盈 `>= 20%`：
  - 只有 `close_qfq < ma50_qfq` 才卖
  - 或从持仓后最高收盘浮盈回撤 `>= 15%` 才卖

### 4. strict_observe

适用范围：

- `strong_trend=True`
- 且持仓浮盈 `>= 15%`

处理规则：

- 命中放量大阴线时，不直接卖，进入最多 `3` 个交易日观察状态；
- 观察期内若满足以下任一条件，则下一交易日开盘卖出：
  - 收盘跌破大阴线当日最低价
  - 收盘跌破 `bbi_qfq`
  - 收盘跌破 `ma20_qfq`
  - 再出现一次放量大阴线
- 若 `3` 个交易日内都未失败，则取消观察，继续持有。

### 5. weekly_hold

适用范围：

- `strong_trend=True`
- 且持仓浮盈 `>= 10%`

处理规则：

- 命中放量大阴线时，不按日线直接卖出；
- 改用已完成周的周线趋势判断：
  - 周收盘 `close_qfq < ma10w_qfq`：进入警戒，但不立即清仓
  - 周收盘 `close_qfq < ma20w_qfq`：下一交易日开盘清仓

数据实现约束：

- 第一轮实验优先使用 `panel.parquet` 的日线 `close_qfq` 自聚合周线；
- 只使用“已完成周”的周线值；
- 不在未结束周内直接使用当周周线，避免未来函数。

## 数据与未来函数约束

### 日线

- `ma20_qfq`、`ma50_qfq` 仅由个股自身历史 `close_qfq` 滚动计算。
- `highest_close_qfq_since_entry` 只在持仓后逐日更新。

### 周线

- 周线只来自信号日之前最后一个已完成周。
- 日级开盘决策不能使用当周未收盘周线。

### 观察状态

- `strict_observe` 的观察状态只能由历史事件推进；
- 不能回看观察期结束后的数据再反推当时应否持有。

## 输出要求

实验脚本至少输出：

- 各模式 `summary.json`
- 各模式 `nav_series.csv`
- 汇总对比表 `comparison.csv`
- 中文总结 `summary.md`

重点比较指标：

- `2018` 年收益率
- 全区间总收益率（若后续扩跑）
- 最大回撤
- Calmar
- 交易次数

## 风险与边界

- 本轮只测试卖出端，若 2018 仍显著亏损，不代表“持有规则无效”，也可能是买入端在熊市仍然过多开仓。
- `weekly_hold` 天然反应更慢，可能改善牛股持有，但也可能放大熊市回撤，因此必须和 `current` 同口径回放。
- 若第一轮 2018 结果全部恶化，则不继续合入正式 `v4`，只保留实验结论。
