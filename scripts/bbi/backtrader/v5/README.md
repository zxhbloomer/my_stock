## 策略设计

### 目标

通过统计每只股票在最近一段时间内持续站上数据库 BBI 的程度，识别相对强势股，再做组合轮动，并与 `v1` 基准结果对比。

`v5` 是独立策略目录。

### 数据来源

| 用途 | 数据表 | 字段 |
|---|---|---|
| 股票基础池 | `tushare_v2."001_stock_basic"` | `ts_code`, `name`, `list_date`, `delist_date`, `list_status` |
| 日线因子 | `tushare_v2."063_stk_factor_pro"` | `trade_date`, `open`, `high`, `low`, `close`, `pre_close`, `open_qfq`, `close_qfq`, `bbi_qfq`, `amount`, `circ_mv`, `adj_factor`, `turnover_rate`, `volume_ratio` |
| 历史 ST | `tushare_v2."004_stock_st"` | `ts_code`, `trade_date` |
| 停牌 | `tushare_v2."030_suspend_d"` | `ts_code`, `trade_date`, `suspend_type` |
| 涨跌停 | `tushare_v2."029_stk_limit"` | `up_limit`, `down_limit` |
| 龙虎榜 | `tushare_v2."088_top_list"` | `ts_code`, `trade_date` |
| 大盘短期大跌过滤/放量阴线风控 | `tushare_v2."137_idx_factor_pro"` | `000001.SH`, `open`, `close`, `amount` |

BBI 必须直接使用数据库字段，不在本地重新计算。

### 防未来函数规则

交易日 `T` 开盘调仓时，只能使用上一个已经完成交易日 `signal_date` 的数据。

所有强度特征都只使用 `trade_date <= signal_date` 的历史数据。

### 强度特征

对每只股票、每个已完成交易日计算：

- `above_bbi`：`close_qfq > bbi_qfq`
- `bbi_distance`：`close_qfq / bbi_qfq - 1`
- `above_ratio_21`, `above_ratio_63`, `above_ratio_126`
- `avg_distance_21`, `avg_distance_63`
- `ret_21`, `ret_63`, `ret_126`
- `volatility_63`
- `amount_ma20`, `circ_mv_ma20`
- `high_pos_21`：当前收盘价 / 近 21 日最高收盘价
- `high_pos_63`：当前收盘价 / 近 63 日最高收盘价
- `pullback_63`：当前前复权收盘价 / 近 63 日最高前复权收盘价 - 1
- `range_pos_63`：当前收盘价在近 63 日收盘价区间中的位置
- `recent_limit_down_20`：近 20 个交易日收盘跌停次数
- `recent_limit_up_20`, `recent_limit_up_63`：近 20/63 个交易日收盘涨停次数
- `turnover_rate_ma20`, `turnover_rate_max20`：近 20 日平均/最大换手率
- `volume_ratio_max20`：近 20 日最大量比
- `lhb_count_20`：近 20 个交易日上龙虎榜次数
- `hot_money_risk_hits`：游资风格风险命中项数量

### 评分

当前评分公式：

```text
score =
  0.30 * z(above_ratio_63)
+ 0.25 * z(above_ratio_126)
+ 0.15 * z(ret_63)
+ 0.10 * z(avg_distance_63)
- 0.15 * z(volatility_63)
+ 0.05 * z(log(amount_ma20))
```

评分是在每个 `signal_date` 的横截面中计算，只使用当日可见信息。

评分前硬过滤：

- `above_ratio_63 >= 0.55`
- `above_ratio_126 >= 0.50`
- `ret_63 >= 0`
- `ret_21 <= 0.45`，强趋势股票例外
- `avg_distance_63 <= 0.18`
- 排除近 1 个月高位风险：`high_pos_21 < 0.95`，强趋势股票例外
- 排除近期跌停风险：`recent_limit_down_20 == 0`
- 排除游资风格风险：`hot_money_risk_hits < 2`
- 当日 `is_eligible = True`
- 大盘短期大跌过滤未触发

强趋势股票定义：

- `above_ratio_63 >= 0.80`
- `above_ratio_126 >= 0.60`
- `ret_63 >= 0.80`
- `recent_limit_down_20 == 0`
- `hot_money_risk_hits < 2`

首笔买入回撤要求：

- 普通股票：`pullback_63 <= -0.05`
- 强趋势股票：`pullback_63 <= -0.03`

启用市场状态后，首笔买入回撤要求按 `signal_date` 的市场状态动态调整：

- 牛市：普通股票 `pullback_63 <= -0.04`，强趋势股票 `pullback_63 <= -0.026`
- 震荡：普通股票 `pullback_63 <= -0.07`，强趋势股票 `pullback_63 <= -0.026`
- 熊市确认后不开仓：上一交易日收盘后市场状态为熊市，则当前交易日开盘不新开仓
- 熊市确认后浮亏卖出：此前已确认熊市，且持仓按上一交易日收盘价计算仍为浮亏或不盈利，则当前交易日开盘卖出；盈利持仓继续持有

市场状态只使用 `signal_date` 及之前的数据：

- 熊市：上证指数距 252 日高点回撤 `<= -20%`，或上证收盘低于 120 日均线、120 日均线 20 日斜率为负、可交易股票池 BBI 宽度 `< 45%`
- 牛市：上证收盘高于 120/200 日均线、120 日均线 20 日斜率为正、252 日回撤 `> -10%`、可交易股票池 BBI 宽度 `>= 55%`
- 其他为震荡；预热不足在日志中记为 `unknown`，交易阈值按震荡处理
- 当前股票池仍来自当前在市且非 ST 股票，历史回测存在幸存者偏差；市场宽度不是严格 point-in-time 全市场宽度。

游资风格风险命中项：

- 近 20 日收盘涨停次数 `>= 2`
- 近 63 日收盘涨停次数 `>= 3`
- 近 20 日平均换手率 `>= 10%`
- 近 20 日最大换手率 `>= 20%`
- 近 20 日最大量比 `>= 3`
- 近 20 日上龙虎榜次数 `>= 2`

这些阈值是工程过滤参数，不是权威公式；它们用于剔除短线异动过强、接力风险偏高的股票。

### 组合规则

- 每月第一个实际交易日开盘调仓。
- 使用上一个交易日作为 `signal_date`。
- 如果 `signal_date` 近 5 日跌幅 <= -4%，则本次不新开仓。
- 如果 `signal_date` 近 20 日最大回撤 <= -8%，则本次不新开仓。
- 短期大跌过滤只阻止新开仓，不强制卖出现有持仓。
- 每个交易日开盘前，用上一完整交易日判断大盘风险：上证指数收阴、单日跌幅 <= -0.7%、成交额 >= 前 20 日均成交额 * 1.2、近 5 日涨跌幅 <= 0。
- 如果大盘风险触发，且某个持仓按上一完整交易日收盘价计算未盈利，则该持仓在当前交易日开盘卖出。
- 大盘放量阴线风控只卖出未盈利持仓，不卖盈利持仓；当天因该风控卖出的股票不会在同一天被调仓逻辑买回。
- 持仓股票如果上一完整交易日收盘跌停，则当前交易日开盘强制尝试卖出；如果停牌、缺行情或开盘仍跌停，则保留为 pending sell，后续交易日继续尝试。
- 过滤通过后，按评分从高到低补齐目标持仓数量。
- 开盘价成交。
- 已有持仓如果仍在 Top `KEEP_TOP_N` 内，则继续持有，减少换手。
- 仓位按资金动态计算：单票目标金额不低于约 10 万，封顶 20 万；50 万资金约持有 5 只，资金扩大后通过增加持仓数量扩容。
- 买入日如果开盘涨停、停牌、缺开盘价，则跳过。
- 卖出日如果开盘跌停、停牌、缺开盘价，则保留为 pending sell，后续交易日继续尝试卖出。
- 持仓期间如 `adj_factor` 变化，会先调整股数和成本，再估值或卖出。

### 股票过滤

- 当前基础池：当前上市、当前非 ST/退、排除北交所和科创板。
- 每日动态过滤：上市满 365 天、历史当日非 ST、未停牌、`amount_ma20 >= 30,000`、`circ_mv_ma20 >= 100,000`。
- 单位沿用现有项目口径：`amount` 为千元，`circ_mv` 为万元。

## 设计与代码评审

专家角色结论：

- 策略设计专家：持续站上 BBI 的比例，比单日 BBI 金叉更适合寻找中长期强势股。
- 数据 QA：必须使用数据库 BBI，并且调仓只能使用前一完整交易日数据；评分不能使用未来实际收益。
- 执行评审：月频轮动比高频追涨更贴近“找周期强势股”的目标。
- 回测 QA：未发现现金重复扣减、买卖方向反、市场过滤未来函数等致命错误；发现未复权成交账本需要 `adj_factor` 调整，已修复。

已知风险：

- 当前基础池仍有幸存者偏差，本轮作为研究口径保留，并在结果中明确说明。
- `close_qfq` 和 `bbi_qfq` 来自数据库因子字段，和现有 BBI 工作流保持一致；严格点时复权仍需要后续专项审计。
- 下方历史结果是 2018-2024 单区间测试留档，后续以最新输出目录中的 `summary.json` 和 `report.html` 为准；下一轮应做 walk-forward 或滚动分段验证，防止参数过拟合。
