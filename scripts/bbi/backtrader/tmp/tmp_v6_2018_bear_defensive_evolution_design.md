# tmp_v6 2018 独立熊市防御策略进化设计

## 目标

继续优化独立熊市 long-only 策略本身，不先接入 `v6` 空仓组合。回测区间固定为 2018 年，并和 `v4`、`v5`、`v6` 做同表对比。

## 证据约束

Tavily 与专家评审给出的方向一致：

- 2018 年纯 A 股 long-only 很难稳定正收益，因此主要目标是少亏、低回撤、比现有策略更稳。
- 防御组合应优先测试红利、低波、质量、轻价值，而不是追涨式强势轮动。
- 行业集中是红利低波策略的主要风险，必须观察并尽量约束。
- 不做大规模参数搜索，不用 2018 结果反推行业白名单。

## 本地数据

- 价格、可交易、热钱风险、涨跌停、停牌：`v6/output/panel.parquet`
- 大盘：`v6/output/market_index.parquet`
- 红利/估值：`tushare_v2."027_daily_basic"` 的 `dv_ttm`, `pb`, `pe_ttm`
- 质量：`tushare_v2."042_fina_indicator"`，按 `ann_date <= signal_date` backward merge
- 行业：`tushare_v2."001_stock_basic".industry`

申万成员表当前为空，因此本轮不声称使用申万行业，只使用 `stock_basic.industry`。

## 候选变体

1. `base_20_monthly`
   - 月频，20 只，等权
   - 低波 + 红利 + 质量 + 轻价值 + 温和动量

2. `industry_cap_30_monthly`
   - 月频，30 只，等权
   - 单行业最多 3 只
   - 用于验证分散持仓和行业约束是否改善 2018

3. `industry_neutral_30_monthly`
   - 月频，30 只，等权
   - 行业内标准化 EP 与相对低波
   - 单行业最多 3 只

4. `quality_trap_30_monthly`
   - 月频，30 只，等权
   - 在变体 3 基础上过滤高股息但现金流/ROE/负债质量差的股票

## 不做的事

- 不接入 `v6` 空仓期组合。
- 不做周频，因为会引入更多换手与参数自由度；先把月频独立策略跑清楚。
- 不使用 `moneyflow`、`cyq_perf`，避免盘后数据 shift 风险。
- 不用 2018 事后收益做选股或行业白名单。

## 评价口径

- 年度收益、最大回撤、Calmar
- 月度收益，尤其看 4月、5月、6月、8月、9月、10月
- 交易次数、买入次数
- 最大行业持仓占比、最大持仓数量行业
- 是否优于 `v5` 和 `v6` 的 2018 亏损/回撤
