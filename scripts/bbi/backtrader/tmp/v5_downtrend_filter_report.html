核心方案定义

最佳方案 block_early_weakness 的规则：

close_qfq < MA20
AND MA20_slope_10 < 0
AND ret_21 < 0

含义：如果个股已经跌破 20 日均线，20 日均线开始下行，且 21 日收益为负，则不进入 v5 候选买入池。这个规则比 MA120 或 lower-high/lower-low 更早，能拦截 v5 原始策略仍可能参与的短期弱势下跌段。

是否合并

建议：暂不作为默认生产逻辑合并。 当前结果足够强，值得进入 v5 正式代码的可配置实验开关；但不建议直接替换默认策略，因为存在参数挖掘、交易次数上升、全候选集过滤影响加仓行为等风险。

可以合并的范围

  • 合并为配置项，例如 DOWNTREND_BUY_FILTER_ENABLED = False，默认关闭。
  • 增加候选过滤原因和统计输出，HTML 报告中展示被过滤数量、影响买入次数、影响加仓次数。
  • 保留 v5 原始逻辑作为 baseline，可一键对比。

不应直接合并的范围

  • 不要直接默认启用 block_early_weakness。
  • 不要合并 initial_only，回测已经显示它显著劣化。
  • 不要合并 block_bbi_breakdown，全周期低于 v5。

下一步

  1. 做稳健性验证：滚动窗口或 walk-forward，例如 2018-2021 训练、2022-2024 验证、2025-2026 样本外确认。
  2. 做参数敏感性：测试 MA10/MA20/MA30、ret_10/ret_21/ret_42、斜率窗口 5/10/20，确认不是单点参数碰巧有效。
  3. 做交易归因：标记每一笔买入/加仓是否因为过滤而改变，输出“被替换买入”“跳过加仓”“新增交易”的 PnL 差异。
  4. 做成本压力测试：提高佣金和滑点，尤其关注交易数从 632 增至 782 后，收益是否仍稳定。
  5. 生产化设计：如果稳健性通过，再把该过滤器放进 v5 `score_candidates` 后、买入前的候选过滤层，并在报告中展示过滤原因。
