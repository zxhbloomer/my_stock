# tmp_v7 主线牛股回踩加仓实验

## 目标

验证用户修正后的策略：牛市先识别市场主线行业，再从主线中找到强趋势牛股，只有这些股票出现健康回踩时才扩展仓位或加仓。熊市沿用 v7，不放宽仓位。

## Tavily 复核

- Moskowitz 与 Grinblatt 的行业动量研究支持“过去赢家行业存在延续性”的方向，但行业动量不是永久有效，需要本地回测验证。
- 相对强度策略通常用横向强弱排序寻找领先资产；趋势过滤能降低把弱势反弹误判为机会的风险。
- 买入回踩只适合已经建立的上升趋势；在下跌趋势中“买跌”容易扩大损失。

## 设计

- 主线行业：用 `001_stock_basic.industry` 分组，从 `signal_date` 的股票池聚合行业 63 日中位收益、21 日中位收益、站上 BBI 比例和低波动排名。暂不使用行业指数，原因是此前 tmp 已确认本地第一版更容易复用股票行业字段；后续可接入 tushare 行业指数或成分表。
- 主线牛股：必须属于主线行业，并满足个股 63/126 日站上 BBI 比例、63 日收益等强趋势条件。
- 健康回踩：收盘价仍在 BBI 上方，离 BBI 不太远；63 日回撤达到阈值；21 日高位位置和短期涨幅不过热。
- 仓位：前 5 只仍按 v7 原始节奏；第 6-10 只只允许主线牛股回踩，单笔 4-5 万；总仓测试 50/55/65 万。
- 加仓：已有持仓仍必须通过 v7 的 `can_add_position`，再额外满足主线牛股回踩，避免高位盲目加仓。
- 止损：默认仍为 -5%；只单独测试“强牛 + 主线回踩标签”的 -8% 宽止损。

## 专家评审

- 量化研究员：主线识别必须是横向排名，不可用 LLM 主观判断；本轮用行业聚合动量和 BBI 广度即可。
- 风控专家：放开仓位的前提是牛市和主线回踩同时成立；不允许普通第 6-10 名扩展买入。
- 数据工程师：所有交易信号来自 `signal_date` panel，不使用交易日当日收盘后的未来信息；但本轮行业主线使用 `stock_basic.industry` 静态行业映射，若历史行业分类发生变化，行业标签存在点时性风险。
- 前端报表专家：报告聚焦全周期、年度、月度、平均现金、平均持股和扩展/回踩加仓次数，合并建议必须直白。

## 计划

1. 写规则函数单元测试，先确认缺失模块失败。
2. 实现隔离实验脚本，复用 v7 回测源码注入，不修改正式 v7。
3. 运行单元测试、编译和回测。
4. 生成 HTML，对比 v4/v5/v6/v7 和本轮实验。
5. 做代码 review 和运行结果 review，给出是否合并建议。
