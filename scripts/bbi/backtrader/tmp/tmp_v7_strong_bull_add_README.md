# tmp_v7 强牛分层加仓实验

目标：验证“不是所有牛市都扩仓，只在强牛中对已盈利且仍在榜内的持仓提高加仓节奏”是否能提升 v7 收益。

## 理论量化

- 不增加新开仓数量，长期持股上限仍为 v7 的 5 只。
- 不改变 v7 的候选排序、入场回撤阈值、熊市过滤、止损和跌停退出。
- 强牛只使用 signal_date 已知数据：`market_regime == bull`、`breadth_above_bbi`、`market_ma120_slope_20`、`market_dd_252`。
- 加仓只发生在原 v7 已满足“持仓仍在候选榜内”的路径中，避免给已走弱持仓补仓。

## Tavily 复核

- 市场广度常用于衡量牛市是否健康；健康牛市通常不是少数股票独涨，而是有较宽参与度。
- Pyramiding/加码盈利持仓是趋势交易中常见但更激进的做法，必须限制在已有浮盈、趋势确认和风险预算内。
- Position sizing 是风控核心，不能为了追求收益取消止损或无限放大单票。

## 设计

- 基准：复现当前 v7。
- 实验 A：强牛提前加仓，盈利阈值从 v7 的 `5%/10%/15%` 降到 `3%/7%/12%`，总仓位上限仍 50 万。
- 实验 B：强牛加仓 1.3 倍，总仓位上限 55 万，阈值保持 v7。
- 实验 C：强牛提前加仓 + 1.3 倍，总仓位上限 55 万。
- 实验 D：严格强牛提前加仓 + 1.3 倍，总仓位上限 55 万，强牛门槛更高。

## 专家角色评审

- 量化研究员：本实验比“牛市盲目扩仓”更可归因，因为只对盈利且仍强势的持仓加码。
- 风控专家：总仓位提升只允许 10%，不增加持股数；若回撤明显恶化，不合并。
- 数据工程师：不需要新增数据；全部使用 v7 已有市场状态快照，避免引入新数据质量问题。
- 开发评审专家：必须保证 sizing 使用 signal_date 昨收估值，不能使用调仓日收盘价。
- 报表专家：报告仍按核心指标、年度、月度和合并建议展示。

## 最终结论

- 不建议合并。本轮所有实际触发强牛加仓的实验均弱于正式 v7。
- 正式 v7 复现：总收益 302.16%，最大回撤 -29.80%。
- 最佳实际触发实验为“强牛加仓1.3_总仓55”：总收益 270.97%，最大回撤 -29.80%，仍低于 v7。
- “严格强牛提前加仓1.3_总仓55”收益等于 v7，但强牛加仓成交为 0，是 no-op，不作为合入候选。
- 下一步应转向失败买入过滤，而不是继续加仓或扩仓。
